# looot

looot gives a scenario one key and one prepaid balance for 2,500+ data endpoints from 90+ providers.

Modules: Find a work email, Verify an email, Enrich a company, Run an operation, Search operations,
Get an operation, Get a run, Get the balance, Watch finished runs, Make an API call.

Connection: an agent token from the looot dashboard (Settings, Agent tokens).

Docs: https://docs.looot.ai. Source: https://github.com/loootai/looot-make
